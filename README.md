# 钢铁守卫

一款原创的网页版 8-bit 坦克防线游戏。规则与节奏向经典四方向坦克游戏致敬，但所有地图、程序绘制的像素图形与合成音效均为原创；本项目与任何原作版权方无隶属关系，也不包含 ROM、原作素材、音乐、音效或关卡布局。

## 游玩

```bash
npm install
npm run dev
```

浏览器打开 Vite 提示的地址。生产构建使用 `npm run build`，生成内容可部署到任意静态托管。

## 操作

- 玩家 1：WASD 移动，F / 空格射击
- 玩家 2：方向键移动，Enter / 右 Ctrl 射击
- ESC：暂停/继续
- M：静音
- 支持前两个已连接的标准 Gamepad（摇杆/D-pad 移动，A/B 射击）
- 键盘与 Gamepad 按钮均可在设置中重新绑定，版本化存档会自动迁移旧设置

## 内容

- 单人战役与本地双人合作
- 35 张程序辅助设计的原创关卡，每关 20 辆敌军
- 普通、快速、重甲、速射四类敌军与局部决策 AI
- 砖墙、钢墙、水面、树林、冰面、基地与六种道具
- 分离显示本关/总计得分、升级、生命、逐关解锁、高分和确定性高周目难度/编成提升
- 浏览器本地存档、音量设置
- 完整关卡编辑器：地形/出生点/敌军队列/难度、撤销重做、本地 CRUD、JSON 导入导出、即时试玩

## 验证

```bash
npm test
npm run build
npm run test:e2e
```

规则模拟采用固定 60Hz tick 与带种子的随机数，和 Canvas、音频、输入相互隔离，便于复现与验证。
